Implementation Notes:
  • Reason for Bill maps to the existing Bill.note column — no schema changes needed. The create_split action in bills_controller.rb would pass the reason param into each bill's note field.
  • Print Bill reuses the existing BillingPrintHelper.print_miscellaneous_bill() method (line 2967 of billing_print_helper.rb). A print_flag hidden field routes the form submission to PDF generation instead of (or before) saving.
  • Line Item Description appears contextually when a "NO METER" parcel is selected (value starts with p-). The meter-specific columns (End Reading, Start/End Date, Cons./Days, Surcharge, Actual Reading) collapse into a single Description text field spanning those columns. The description saves to the same Bill.note column per-line. The meter_id change handler in _split_bill_form.html.erb already fires on selection change — the toggle logic hooks into this existing event.
  • All three features are additive — they don't change existing split_bill behavior for users who don't use them.
